# YOLO RKNN Models

Place the YOLO RKNN model files expected by the runtime in this directory.

Known runtime paths include:

- `rknn_lt.rknn`
- `rknn_lt_new.rknn`
- `rknn_lt_old.rknn`
- `rknn_lt1.rknn`

Model weights are not committed by default. Confirm training-data and redistribution rights before publishing them through Git LFS or release assets.
