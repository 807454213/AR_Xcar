# PPOCR RKNN Models

Place OCR detection and recognition RKNN model files here.

Known runtime paths include:

- `OCRv4_det.rknn`
- `ppocrv4_det_i8.rknn`
- `model_rec.rknn`
- `ppocrv4_rec_fp.rknn`

Model weights and font files may carry their own licenses. Verify redistribution rights before publishing them.
