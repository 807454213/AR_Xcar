# Xcar 终端输出收敛设计

日期：2026-07-25

## 目标

减少整车程序运行时的终端噪声，只保留调试路牌识别链路所需的信息、模型初始化信息和一次性致命错误。日志调整不得改变 OCR、LLM、控制状态机、串口或模型推理行为。

## 保留的输出

正常运行时只保留以下类别：

1. `[MODEL INIT]`：YOLO、PPSeg、OCR 模型初始化的关键结果。每次模型初始化只输出必要的一行成功或失败信息，不输出模型张量、队列、线程或性能细节。
2. `[OCR RAW]`：OCR 识别器直接返回、尚未经过聚合、纠错或策略筛选的非空文本。每条原始文本单独输出，不附带帧号、置信度、检测框或 strong/context 标记。
3. `[LLM INPUT]`：实际提交给 LLM 的最终文本。每次真正提交请求时输出一次；多条文本逐条输出。如果本地规则直接完成决策且没有请求 LLM，则不输出该类别。
4. `[LLM RESULT]`：LLM 请求解析后的最终决策结果，保留 action、flag、confidence 和 source 等现有决策摘要，不输出 HTTP 响应正文、鉴权响应或中间解析过程。
5. `[FATAL]`：导致功能不可用或程序退出的模型、串口、配置等错误。同一个错误键在单次进程运行期间最多输出一次，避免循环刷屏。

## 删除或静默的输出

以下信息不再输出到终端：

- DriveState、SIGN、FORK、行人、车辆、金币等状态机过程；
- UART 指令发送、状态切换和正常启动/停止过程；
- OCR processor 激活、session、尝试次数、候选统计和流水线阶段；
- AI 帧号、检测框、置信度、队列、FPS 和性能统计；
- LLM 请求提交过程、过期请求、HTTP 响应正文、token 响应和本地兜底过程；
- 共享内存、UDS、配置加载等正常成功信息；
- 其他调车调试输出。

文件写入所用的 `fprintf` 不属于终端日志，不应改动。

## 实现方式

新增一个小型、无业务依赖的终端输出组件，提供以下明确接口：

- `modelInit(component, message)`
- `ocrRaw(text)`
- `llmInput(text)`
- `llmResult(command)`
- `fatalOnce(key, message)`

业务代码不再直接用 `printf`、`std::cout` 或 `std::cerr` 输出运行日志。现有保留内容迁移到统一接口，其余输出语句删除。低层模型代码中当前参与主程序构建的初始化输出也进行收敛；第三方未参与构建的示例代码和测试程序不在本次范围。

`fatalOnce` 在进程内保存已输出的错误键，使用线程安全保护，保证异步 OCR、LLM 或硬件线程同时报告相同问题时仍只出现一条。

终端输出组件只负责格式和去重，不读取配置，也不改变现有 `verboseLogs` 配置的序列化兼容性。`verboseLogs` 可以继续保留在配置结构中，但正式主程序不再依赖它恢复已删除的调试刷屏。

## 数据流

OCR 推理产生文本后立即调用 `ocrRaw()`，随后结果继续按现有逻辑进入聚合器。聚合器生成 `sign_texts` 后，只有 `LlmCall::Async(sign_texts)` 确实进入提交路径时才逐条调用 `llmInput()`。LLM future 完成并解析为 `ControlCommand` 后调用 `llmResult()`，然后按现有 session 校验和状态机路径应用结果。

这确保终端能直接比较：

```text
[OCR RAW] ...
[LLM INPUT] ...
[LLM RESULT] ...
```

而不会把聚合器调试信息误认为真正提交内容。

## 错误处理

模型初始化成功或失败属于 `[MODEL INIT]`；如果失败导致关键能力不可用或程序退出，可同时归入 `[FATAL]`，但同一事件不得重复输出两行。串口不可用、比赛模式无法启动、配置无法读取等关键错误使用 `[FATAL]`。可恢复的单帧推理失败、重复写失败或状态超时不再逐帧输出。

## 测试

采用测试先行方式：

1. 先增加终端输出组件测试，捕获输出流并验证五类格式；
2. 验证空 OCR 文本不输出；
3. 验证同一 fatal key 只输出一次、不同 key 各输出一次；
4. 验证多条 LLM 输入保持原顺序；
5. 增加源码策略检查，阻止主程序业务目录重新引入未纳管的终端输出；排除配置文件写入和测试程序；
6. 运行现有 SIGN OCR、LLM、session isolation 和构建验证，确认只有日志行为变化。

## 修改边界

- 保留 `src/io/llm_decision.cpp` 当前未提交的提示词修改，不覆盖或回退。
- 不修改配置参数值。
- 不修改 OCR 聚合结果、LLM 请求内容、LLM 解析结果或车控决策。
- 不修改测试可执行文件自身用于报告成功/失败的输出。
- 不改动未参与主程序构建的第三方示例源码。
