# 金币阈值内候选回退设计

## 目标

当最近的候选金币超过 `goldErrorFixedYMin` 时，优先使用同帧中阈值以内最靠近车辆的候选金币作为动态误差行，而不是立即回到固定 `errorCalcY`。

## 选择顺序

- 候选金币继续使用现有尺寸、`goldFollowMinY`、`goldXMin/goldXMax`、ForkExit 和可达性过滤。
- `GOLD_BAND/GOLD_SLOW` 每帧同时计算：
  - 全部候选金币的最大映射 y；
  - 满足 `y < goldErrorFixedYMin` 的候选金币最大映射 y。
- 当全部候选最大 y 未超过阈值时，使用该最大 y。
- 当全部候选最大 y 超过阈值时，优先使用阈值内候选最大 y；阈值内没有候选才使用固定 `base_error_y`。
- 当前帧没有候选时保留锁定金币回退；锁定金币超过阈值且没有阈值内当前候选时使用固定行。
- 赛道内-only 始终使用固定行，不改变。

## 加权方式

- 选中候选金币 y：使用 `goldErrorCalcBand` 向上加权。
- 回到固定行：使用 `errorCalcBand` 上下对称加权。

## 验证

- 增加“一个金币超过阈值、另一个金币低于阈值”的 GOLD_BAND/GOLD_SLOW 测试，断言选择阈值内最大 y。
- 保留“全部金币超过阈值则固定行”的测试。
- 运行金币回归、删除元素回归和主程序构建。
